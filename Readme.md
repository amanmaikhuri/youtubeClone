# 🎥 StreamSnap - Video Streaming UI

StreamSnap is a lightweight, responsive video streaming frontend built using HTML, CSS, and JavaScript. The project mimics a streaming platform with features like theme toggling (light/dark), search filtering, and dynamic rendering of video content from a JSON file.

## 🚀 Features

- 🎨 **Light/Dark Theme Toggle**
- 🔍 **Search Functionality** — Filter videos by title or creator
- 🧩 **Dynamic Content Rendering** from external `videos.json` file
- 📱 **Responsive Layout** for mobile, tablet, and desktop
- 🔧 **Interactive Sidebar Navigation**
- 🧠 **Vanilla JavaScript logic** without any frontend frameworks

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (with Flexbox & Media Queries)
- JavaScript (ES6+)
- Font Awesome (for icons)
